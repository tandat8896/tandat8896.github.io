# Product logo sources

These are product/project logos, used for identification only. All trademarks remain with their owners; inclusion does not imply endorsement. Generic VM, network and internal-function glyphs in the diagrams are original drawings, not AWS service icons.

- Oracle, PostgreSQL, Apache Spark, Apache Hadoop, Apache Kafka, Rust, NixOS: original SVG assets from [Devicon](https://github.com/devicons/devicon/tree/master/icons), distributed under the repository's [MIT license](https://github.com/devicons/devicon/blob/master/LICENSE). Upstream icon directory names: oracle, postgresql, apachespark, hadoop, apachekafka, rust, nixos. Brand rights remain separate from that license.
- Apache Iceberg: [official website logo](https://iceberg.apache.org/assets/images/Iceberg-logo.svg).
- Apache ZooKeeper: [official website logo](https://zookeeper.apache.org/images/logo.svg).
- Debezium and Confluent: reused SVG brand artwork from the owner's existing project assets at `training_pytorch_spark/docs/icons/vlz-debeziumio.svg` and `vlz-confluentio.svg`. Original upstream licensing/provenance was not included alongside those local files; no broader redistribution license is asserted here. Brand owners: [Debezium](https://debezium.io/) and [Confluent](https://www.confluent.io/).

- Apache Flink and Python: reused existing SVG brand assets from `training_pytorch_spark/docs/icons/apacheflink.svg` and `python.svg`.
- Streamlit and Supabase: original assets from the corresponding directories in [Devicon](https://github.com/devicons/devicon/tree/master/icons), MIT license with separate brand rights.
- Tableau: [Simple Icons 11.0.0](https://cdn.jsdelivr.net/npm/simple-icons@11.0.0/icons/tableau.svg); Simple Icons artwork is CC0, brand rights remain with the owner.

Retrieved/reused 2026-09-14. The renderer embeds these assets in the downloadable SVG and draw.io diagrams.
